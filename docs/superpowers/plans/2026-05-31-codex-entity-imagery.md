# Codex Entity Imagery (kanim → animated WebP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show entity imagery in the Codex panel — wire the already-extracted building/element icons immediately, then build a kanim→animated-WebP pipeline so critters, plants, and geysers get looping idle animations.

**Architecture:** Two phases that each ship working software. **Phase 1 (backend + frontend)**: `CodexController` resolves an image URL from an entry's linked entity (`/assets/game/<cat>/<key>.webp`) with a file-existence guard, and the Vue panel renders it; entities without an asset degrade gracefully (no image). **Phase 2 (extraction)**: a Python pipeline reads ONI's Unity `.assets` with UnityPy, pulls each entity's kanim `*_build`/`*_anim` TextAssets plus its atlas Texture2D, parses the Klei kanim binary format, composites the idle animation's frames with Pillow, and writes a looping animated `.webp` per entity into `public/assets/game/{critters,plants,geysers}/`. Because the kanim byte layout varies by version, Task 1 is a validation spike that pins the exact format against real bytes before any parser code is written; later parser tasks reconcile against that spike output.

**Tech Stack:** Laravel 13 / spatie-laravel-data / Pest (backend) · Vue 3 + Inertia (frontend) · Python 3 managed with **uv** + UnityPy + Pillow (extraction). All Python runs via `uv run --with <pkgs> python -m ...` (ephemeral env, no global installs, no committed venv); modules are run with `-m` from the repo root so `from scripts.kanim...` imports resolve.

**Asset facts (confirmed during planning):**
- Existing assets: `public/assets/game/{buildings(370),elements(171)}/<NaturalKey>.webp`; `critters`, `plants`, `geysers` dirs exist but are empty.
- Element images are served as `/assets/game/elements/<ElementId>.webp` and keyed by the PascalCase natural id (e.g. `Aluminum.webp`, `Hatch` would be `Hatch.webp`).
- ONI `.assets` live at `game-data/OxygenNotIncluded_Data/*.assets` (repo copy) and at `/mnt/d/SteamLibrary/steamapps/common/OxygenNotIncluded/OxygenNotIncluded_Data/*.assets` (live). `sharedassets0.assets` (~381 MB) holds the kanim TextAssets + atlas textures.
- `scripts/extract-assets.py` already uses UnityPy + Pillow against `game-data/OxygenNotIncluded_Data/sharedassets0.assets`; reuse that path and dependency.
- Codex link types in the DB today: `App\Models\Critter` (22), `App\Models\Plant` (29). `CodexController::links()` already loads `buildings/elements/critters/plants/geyserTypes` relations with their natural keys.

**Validated approach (end-to-end proof on Hatch, 2026-05-31 — supersedes guesses in Tasks 5-8):**
- **Format confirmed:** BILD v10, ANIM v5. Build symbol header: `hash:i`, `path:i` (v>=10), `color:u`, `flags:i`, `numFrames:i`; build frame: `sourceFrame:i`, `duration:i`, `buildImageIdx:i`, `pivotX/Y/W/H:f`, `x1/y1/x2/y2:f` (UV). Anim element: `symbolHash:i`, `frameIndex:i`, `folder:i`, `flags:i`, `a/b/g/r:f`, `m1/m2/m3/m4:f`, `tx/ty:f`, `order:f`. EOF self-check (hash-table lands exactly at end) confirmed both.
- **Multi-build merge (critical):** a creature is split across several builds, each with its OWN atlas, e.g. `hatch_build` (effects) + `hatch_build_build` (body). The anim references symbols across all of them. Build a symbol table `hash -> (frames, atlas)` by merging every build named `{base}_build` or `{base}_build_*`, mapping each to its atlas `name[:-len("_build")] + "_0"`.
- **Half-res atlas:** `pivotWidth/Height` is 2× the atlas crop size. Resize each cropped symbol to `(pivotW, pivotH)` so the pivot and element matrix line up (robust to any ratio).
- **Transform (confirmed empirically):** element matrix used as-is — world = M·(local − pivot) + t with M = [[m1,m3],[m2,m4]], `t = (tx, ty)` (positive ty), no UV flip. Render to a margined canvas, then crop every frame to the *union* of non-transparent bounds for stable framing.
- **Filter the editor pivot gizmo:** the anim includes a non-visual RGB-axis marker symbol; skip it by name (denylist e.g. `pivot`, `snapto`).
- **Output size:** lossless WebP is ~600 KB/critter; use lossy `quality≈80` (and a ~160px tall canvas) to keep ~100 entities reasonable.

"""Throwaway probe: locate a critter's kanim assets and dump binary headers."""
import struct
import sys
from pathlib import Path

import UnityPy

ASSETS = Path(__file__).resolve().parents[2] / "game-data/OxygenNotIncluded_Data/sharedassets0.assets"
NEEDLE = sys.argv[1] if len(sys.argv) > 1 else "hatch"


def main() -> None:
    env = UnityPy.load(str(ASSETS))
    text, tex = {}, {}
    for obj in env.objects:
        if obj.type.name == "TextAsset":
            d = obj.read()
            if NEEDLE in d.m_Name.lower():
                text[d.m_Name] = bytes(d.m_Script.encode("utf-8", "surrogateescape")) if isinstance(d.m_Script, str) else bytes(d.m_Script)
        elif obj.type.name == "Texture2D":
            d = obj.read()
            if NEEDLE in d.m_Name.lower():
                tex[d.m_Name] = d.image.size

    print("TextAssets:", sorted(text))
    print("Textures:", tex)

    for name, raw in text.items():
        if name.endswith("_build"):
            magic = raw[:4]
            version, symbols, frames = struct.unpack_from("<iii", raw, 4)
            print(f"\n{name}: magic={magic!r} version={version} symbols={symbols} frames={frames}")
            namelen = struct.unpack_from("<i", raw, 16)[0]
            print("  build-name:", raw[20:20 + namelen].decode("ascii", "replace"), "len", namelen)
        if name.endswith("_anim"):
            magic = raw[:4]
            version = struct.unpack_from("<i", raw, 4)[0]
            head = struct.unpack_from("<iii", raw, 8)
            print(f"\n{name}: magic={magic!r} version={version} next3={head}")


if __name__ == "__main__":
    main()

```python
"""Little-endian binary reader for Klei kanim files."""
import struct


class BinaryReader:
    def __init__(self, data: bytes) -> None:
        self._data = data
        self._pos = 0

    def int32(self) -> int:
        value = struct.unpack_from("<i", self._data, self._pos)[0]
        self._pos += 4
        return value

    def uint32(self) -> int:
        value = struct.unpack_from("<I", self._data, self._pos)[0]
        self._pos += 4
        return value

    def float32(self) -> float:
        value = struct.unpack_from("<f", self._data, self._pos)[0]
        self._pos += 4
        return value

    def magic(self) -> bytes:
        value = self._data[self._pos:self._pos + 4]
        self._pos += 4
        return value

    def string(self) -> str:
        length = self.int32()
        raw = self._data[self._pos:self._pos + length]
        self._pos += length
        return raw.decode("ascii", "replace")

    def eof(self) -> bool:
        return self._pos >= len(self._data)
```

```python
"""Parser for Klei kanim *_build.bytes (symbols, frames, atlas UVs)."""
from dataclasses import dataclass, field

from scripts.kanim.reader import BinaryReader


@dataclass
class BuildFrame:
    source_frame: int
    duration: int
    build_image_index: int
    pivot_x: float
    pivot_y: float
    pivot_w: float
    pivot_h: float
    uv: tuple[float, float, float, float]  # x1, y1, x2, y2 (normalized)


@dataclass
class BuildSymbol:
    hash: int
    name: str
    frames: list[BuildFrame] = field(default_factory=list)


@dataclass
class Build:
    name: str
    version: int
    symbols: list[BuildSymbol]
    hashes: dict[int, str]

    def symbol(self, symbol_hash: int) -> BuildSymbol:
        for symbol in self.symbols:
            if symbol.hash == symbol_hash:
                return symbol
        raise KeyError(symbol_hash)


def parse_build(data: bytes) -> Build:
    r = BinaryReader(data)
    assert r.magic() == b"BILD", "not a BILD file"
    version = r.int32()
    symbol_count = r.int32()
    r.int32()  # total frame count (unused; per-symbol counts drive parsing)
    name = r.string()

    symbols: list[BuildSymbol] = []
    for _ in range(symbol_count):
        symbol_hash = r.int32()
        if version >= 10:
            r.int32()  # path hash (unused)
        r.uint32()  # color (unused)
        r.int32()  # flags (unused)
        num_frames = r.int32()
        frames: list[BuildFrame] = []
        for _ in range(num_frames):
            source_frame = r.int32()
            duration = r.int32()
            build_image_index = r.int32()
            pivot_x = r.float32()
            pivot_y = r.float32()
            pivot_w = r.float32()
            pivot_h = r.float32()
            uv = (r.float32(), r.float32(), r.float32(), r.float32())
            frames.append(BuildFrame(source_frame, duration, build_image_index, pivot_x, pivot_y, pivot_w, pivot_h, uv))
        symbols.append(BuildSymbol(symbol_hash, "", frames))

    hashes: dict[int, str] = {}
    hash_count = r.int32()
    for _ in range(hash_count):
        h = r.int32()
        hashes[h] = r.string()

    for symbol in symbols:
        symbol.name = hashes.get(symbol.hash, str(symbol.hash))

    return Build(name=name, version=version, symbols=symbols, hashes=hashes)
```

```python
"""Parser for Klei kanim *_anim.bytes (animations, frames, element transforms)."""
from dataclasses import dataclass, field

from scripts.kanim.reader import BinaryReader


@dataclass
class AnimElement:
    symbol_hash: int
    frame_index: int
    matrix: tuple[float, float, float, float]  # m1, m2, m3, m4
    translation: tuple[float, float]
    order: float


@dataclass
class AnimFrame:
    x: float
    y: float
    w: float
    h: float
    elements: list[AnimElement] = field(default_factory=list)


@dataclass
class Anim:
    name: str
    rate: float
    frames: list[AnimFrame] = field(default_factory=list)


@dataclass
class AnimData:
    version: int
    anims: list[Anim]

    def anim(self, name: str) -> Anim:
        for anim in self.anims:
            if anim.name == name:
                return anim
        raise KeyError(name)


def parse_anim(data: bytes) -> AnimData:
    r = BinaryReader(data)
    assert r.magic() == b"ANIM", "not an ANIM file"
    version = r.int32()
    r.int32()  # maxVisSymbolFrames (unused)
    r.int32()  # total frame count (unused)
    anim_count = r.int32()

    anims: list[Anim] = []
    for _ in range(anim_count):
        name = r.string()
        r.int32()  # root symbol hash (unused)
        rate = r.float32()
        frame_count = r.int32()
        frames: list[AnimFrame] = []
        for _ in range(frame_count):
            x, y, w, h = r.float32(), r.float32(), r.float32(), r.float32()
            element_count = r.int32()
            elements: list[AnimElement] = []
            for _ in range(element_count):
                symbol_hash = r.int32()
                frame_index = r.int32()
                r.int32()  # folder hash (unused)
                r.int32()  # flags (unused)
                r.float32(); r.float32(); r.float32(); r.float32()  # a, b, g, r color (unused)
                m1, m2, m3, m4 = r.float32(), r.float32(), r.float32(), r.float32()
                tx, ty = r.float32(), r.float32()
                order = r.float32()
                elements.append(AnimElement(symbol_hash, frame_index, (m1, m2, m3, m4), (tx, ty), order))
            frames.append(AnimFrame(x, y, w, h, elements))
        anims.append(Anim(name=name, rate=rate, frames=frames))

    return AnimData(version=version, anims=anims)
```

```python
"""Composite kanim frames over the atlas and encode a looping animated WebP."""
from PIL import Image

from scripts.kanim.anim import Anim
from scripts.kanim.build import Build

CANVAS_PX = 128  # target tall side


def _symbol_image(build: Build, atlas: Image.Image, symbol_hash: int, frame_index: int) -> Image.Image | None:
    try:
        symbol = build.symbol(symbol_hash)
    except KeyError:
        return None
    if not symbol.frames:
        return None
    frame = symbol.frames[min(frame_index, len(symbol.frames) - 1)]
    x1, y1, x2, y2 = frame.uv
    aw, ah = atlas.size
    left, upper, right, lower = int(x1 * aw), int(y1 * ah), int(x2 * aw), int(y2 * ah)
    if right <= left or lower <= upper:
        return None
    return atlas.crop((left, upper, right, lower))


def render_frame(build: Build, atlas: Image.Image, anim: Anim, frame_idx: int, scale: float, bbox: tuple[float, float, float, float]) -> Image.Image:
    bx, by, bw, bh = bbox
    canvas_w = max(1, int(bw * scale))
    canvas_h = max(1, int(bh * scale))
    canvas = Image.new("RGBA", (canvas_w, canvas_h), (0, 0, 0, 0))

    frame = anim.frames[frame_idx]
    for element in sorted(frame.elements, key=lambda e: e.order, reverse=True):
        sprite = _symbol_image(build, atlas, element.symbol_hash, element.frame_index)
        if sprite is None:
            continue
        m1, m2, m3, m4 = element.matrix
        tx, ty = element.translation
        # Klei element matrix is [m1 m2 m3 m4] with translation (tx, ty), in anim units.
        # Pillow affine wants the inverse mapping (output->input); build it from the 2x3.
        a, b, c, d = m1, m2, m3, m4
        e_tx = (tx - bx) * scale + canvas_w / 2
        e_ty = (ty - by) * scale + canvas_h / 2
        det = a * d - b * c
        if abs(det) < 1e-8:
            continue
        ia, ib, ic, id_ = d / det, -b / det, -c / det, a / det
        # account for symbol pivot so the sprite rotates/scales about its pivot
        placed = Image.new("RGBA", (canvas_w, canvas_h), (0, 0, 0, 0))
        sw, sh = sprite.size
        inv = (
            ia / scale, ib / scale, (-e_tx * ia - e_ty * ib) / scale + sw / 2,
            ic / scale, id_ / scale, (-e_tx * ic - e_ty * id_) / scale + sh / 2,
        )
        warped = sprite.transform((canvas_w, canvas_h), Image.AFFINE, inv, resample=Image.BILINEAR)
        placed.alpha_composite(warped)
        canvas.alpha_composite(placed)

    return canvas


def render_idle_webp(build: Build, atlas: Image.Image, anim: Anim, out_path) -> None:
    if not anim.frames:
        raise ValueError("anim has no frames")
    bx = min(f.x - f.w / 2 for f in anim.frames)
    by = min(f.y - f.h / 2 for f in anim.frames)
    bw = max(f.x + f.w / 2 for f in anim.frames) - bx
    bh = max(f.y + f.h / 2 for f in anim.frames) - by
    scale = CANVAS_PX / max(bw, bh) if max(bw, bh) > 0 else 1.0

    images = [render_frame(build, atlas, anim, i, scale, (bx, by, bw, bh)) for i in range(len(anim.frames))]
    duration_ms = max(1, int(1000 / max(anim.rate, 1.0)))
    images[0].save(
        out_path,
        "webp",
        save_all=True,
        append_images=images[1:],
        duration=duration_ms,
        loop=0,
        lossless=True,
        disposal=2,
    )
```

"""Render looping idle animations for worklist entities into public/assets/game/."""
import sys
from pathlib import Path

import UnityPy
from PIL import Image

from scripts.kanim.anim import parse_anim
from scripts.kanim.build import parse_build
from scripts.kanim.mapping import load_worklist
from scripts.kanim.render import render_idle_webp

REPO = Path(__file__).resolve().parents[2]
ASSETS = REPO / "game-data/OxygenNotIncluded_Data/sharedassets0.assets"
IDLE_PREFERENCES = ("idle_loop", "idle_default", "idle")


def _raw(text_asset) -> bytes:
    script = text_asset.m_Script
    return script.encode("utf-8", "surrogateescape") if isinstance(script, str) else bytes(script)


def _pick_idle(anim_data):
    names = [a.name for a in anim_data.anims]
    for pref in IDLE_PREFERENCES:
        for a in anim_data.anims:
            if a.name == pref:
                return a
    for a in anim_data.anims:
        if "idle" in a.name:
            return a
    return anim_data.anims[0] if anim_data.anims else None


def main() -> None:
    env = UnityPy.load(str(ASSETS))
    texts: dict[str, bytes] = {}
    textures: dict[str, Image.Image] = {}
    for obj in env.objects:
        if obj.type.name == "TextAsset":
            d = obj.read()
            texts[d.m_Name] = _raw(d)
        elif obj.type.name == "Texture2D":
            d = obj.read()
            textures[d.m_Name] = d.image

    worklist = load_worklist()
    ok = miss = 0
    for row in worklist:
        base = row["kanim"]
        build_bytes = texts.get(f"{base}_build")
        anim_bytes = texts.get(f"{base}_anim")
        atlas = textures.get(f"{base}_0")
        if not build_bytes or not anim_bytes or atlas is None:
            print(f"  MISS  {row['category']}/{row['key']} (kanim '{base}' not found)")
            miss += 1
            continue
        build = parse_build(build_bytes)
        anim = _pick_idle(parse_anim(anim_bytes))
        if anim is None:
            print(f"  MISS  {row['category']}/{row['key']} (no anim)")
            miss += 1
            continue
        out_dir = REPO / "public/assets/game" / row["category"]
        out_dir.mkdir(parents=True, exist_ok=True)
        render_idle_webp(build, atlas.convert("RGBA"), anim, out_dir / f"{row['key']}.webp")
        print(f"  OK    {row['category']}/{row['key']} ({base}, {len(anim.frames)}f)")
        ok += 1

    print(f"\nDone: {ok} rendered, {miss} missing.")
    sys.exit(0)


if __name__ == "__main__":
    main()
