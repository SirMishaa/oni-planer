# Bâtiments

La page des bâtiments les regroupe par catégorie du menu de construction. Tape dans la recherche pour filtrer par nom, ou choisis une catégorie pour n'afficher que ses bâtiments.

Ouvre un bâtiment pour voir :

- **Construction** : les matériaux et quantités nécessaires, et le temps de construction ;
- **Emprise** : sa largeur et sa hauteur en cases ;
- **Chaleur** : la chaleur qu'il dégage ;
- **Production** : l'électricité qu'il consomme ou produit.

La description et l'effet donnés par le jeu s'affichent avec.
